Environment check

/qme-env-audit

See where case data goes in your AI account, what can be verified right now, and what to fix before you rely on it for real evaluations.

Get the environment check

What happens when you run it

  1. It asks one question at a time about how you and your staff use the account: who logs in, where files go, what is kept, what gets emailed.
  2. Each answer is marked verified, reported, or unknown. An assumption is never quietly turned into a pass.
  3. You get a short list of findings in priority order, each with the evidence, why it matters for a QME, and the fix.
  4. Fix the top items, run it again, and confirm the gap closed.

What good looks like

  1. 01Each person has their own login. No shared accounts.
  2. 02Case data stays inside a known, bounded environment.
  3. 03Model and vendor access is explicit, not assumed.
  4. 04PHI does not leak through convenience tools like email or chat.
  5. 05Retention and deletion are decisions, not accidents.
  6. 06Backups and recovery are understood before they are needed.
EXAMPLE OUTPUT · /qme-env-audit P0
HIGH: PHI may be exposed through external email
Status: VERIFIED
EVIDENCE
Completion messages include patient identifiers in external email bodies.
WHY IT MATTERS
This creates an unnecessary PHI egress path outside any controlled boundary.
RECOMMENDED ACTION
Remove patient identifiers from email and require authenticated access for case materials.
Priority: P0 · Contain, Consolidate, Harden, Verify, Scale
One finding among many the check produces from a single environment scan. Example output.

What it is not

This is a readiness check, not legal advice, a HIPAA certification, or a determination that your practice is a Covered Entity or Business Associate.

Get the environment check

  1. Download the environment check (zip)
  2. In Claude, open Settings, then Capabilities, then Skills, and upload it.
  3. Start a new chat and type /qme-env-audit.
Needs a Claude Pro, Max, Team, or Enterprise plan with code execution turned on. Run it before any real case goes into that account.
Compatibility Claude web and desktop by upload (Pro, Max, Team, Enterprise, with code execution on); Claude Code and Codex by command. Other skill-aware agents untested.
