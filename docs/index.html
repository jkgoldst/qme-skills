STAGE 01 · SAFE ENVIRONMENT
QME AI Setup Review

Audit your QME AI setup before using real case data.

Describe your tools and workflow. Get a map of where case data goes, a prioritized list of gaps, and specific questions for your vendor or technical support.

Install the review See a complete example

What is a skill? Reusable instructions you install in an AI assistant. This one guides an interview and evidence review, adapted to the controls you own.

No patient files needed. Use fictional descriptions and redacted evidence. Keep passwords, API keys, and patient identifiers out of the audit.

What you get. A workflow map, scoped findings, and an action plan. The review identifies gaps and unknowns; it does not certify an account for patient data or make changes.

  1. Download the skill ZIP.
  2. In Claude, enable code execution in Settings → Capabilities. Open Customize → Skills → + → Create skill → Upload a skill, and upload the ZIP.
  3. Enable the skill. Start a new chat and ask: Use qme-env-audit to review my QME AI setup. Start with my tools and workflow. No patient files.

Your organization may restrict custom skills. Installing a skill does not change your account's data-handling terms. Claude installation help.

What good looks like

Identity Storage Model Output Retention Recovery
  1. 01Each person has an individual identity: no shared logins.
  2. 02Case data stays inside a known, bounded environment.
  3. 03Model and vendor access is explicit, not assumed.
  4. 04PHI does not leak through convenience tools like email or chat.
  5. 05Retention and deletion are intentional, not accidental.
  6. 06Backups and recovery are understood before they are needed.
Full methodology in GitHub / docs.

How the skill works

It asks one question at a time and adapts to your role: using an AI service, buying a managed application, or operating software. It separates inspected evidence, reported claims, and unknowns. You can answer “I don’t know.”

  1. Know the boundary
    Map where case data enters, moves, and lives.
  3. Verify
    Separate what’s proven from what’s merely stated.
  5. Plan
    Name priority actions and who can resolve them.
  7. Re-check
    Review new evidence after a change.

Choose your operating model

The review can help clarify responsibilities in either model. Installing the skill does not implement controls or establish that an environment meets a standard.
