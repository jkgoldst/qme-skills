For technical users

These are Agent Skills: a folder with a SKILL.md and supporting files, MIT licensed, source on GitHub.

Copy a skill folder from skills/ into your agent's skills folder (for Claude Code, ~/.claude/skills/), then run it by name, for example /case-facts.
